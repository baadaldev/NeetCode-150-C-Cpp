## 📌 Problem Overview
- **Topic:** Heap / Priority Queue
- **LeetCode ID:** [703 - Kth Largest Element in a Stream](https://leetcode.com/problems/kth-largest-element-in-a-stream/)
- **Difficulty:** 🟢 Easy
- **Time Complexity:** `O(n log k)`
- **Space Complexity:** `O(k)`

---

## 💡 Algorithmic Approach & Summary
Maintain a min-heap of capacity k. The heap's top always holds the kth largest element.
